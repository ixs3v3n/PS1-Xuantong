# Trust and Equitable Access in Digital Markets

## PS1 Research Proposal

**COMSCI/ECON 206 — Computational Microeconomics**  
**Autumn 2026 Session 1**

This repository contains the research proposal and computational artifacts for
my PS1 project:

> **Trust and Equitable Access in Digital Markets**

The project studies how platform rules, reputation information, and income
uncertainty jointly affect trust, speculation, and genuine consumer access to
scarce goods.
